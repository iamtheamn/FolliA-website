Politique de confidentialité

Application Android FolliA (com.iamtheamn.aimen) · Dernière mise à jour : 12 novembre 2026

En bref

FolliA ne collecte aucune donnée. L'application n'a ni compte utilisateur, ni publicité, ni outil de mesure d'audience, et son développeur n'exploite aucun serveur : il ne reçoit donc jamais vos conversations, vos réglages ou vos identifiants.

Données enregistrées sur votre appareil

  • Conversations : vos messages et les réponses de vos modèles sont enregistrés dans une base de données locale, dans l'espace privé de l'application.
  • Réglages d'interface : langue, thème, couleur et voix choisie.
  • Paramètres de connexion : l'adresse et le port de votre serveur Ollama, ainsi que vos identifiants Nextcloud si vous les saisissez, sont chiffrés à l'aide de l'Android Keystore.

Ces données sont exclues des sauvegardes automatiques d'Android et du transfert d'appareil à appareil.

Données qui quittent votre appareil

FolliA n'envoie des données qu'aux services que vous configurez ou activez vous-même :

  • Votre serveur Ollama : vos messages et l'historique de la conversation en cours sont envoyés à l'adresse que vous avez saisie, afin d'obtenir une réponse. Ce serveur est le vôtre ; FolliA ne passe par aucun intermédiaire. Si vous n'utilisez pas d'adresse en « https:// », cet échange n'est pas chiffré par l'application : utilisez-le sur un réseau de confiance ou à travers un VPN.
  • Votre serveur Nextcloud (facultatif) : si vous activez la synchronisation, une copie de vos conversations est envoyée en HTTPS vers le serveur Nextcloud que vous avez indiqué.
  • Modèles de dictée (facultatif) : si vous téléchargez un modèle de langue depuis Réglages > Voix, FolliA le récupère une seule fois sur le site du projet open source Vosk (alphacephei.com). Ce site voit alors votre adresse IP ; aucune autre information n'est transmise.
  • Lecture à voix haute (facultatif) : le texte des réponses est transmis au moteur de synthèse vocale de votre appareil.
  • Vérification des mises à jour : au démarrage, l'application interroge GitHub pour savoir si une nouvelle version existe. GitHub voit alors votre adresse IP, comme pour toute visite d'un site web. Aucune autre information n'est transmise.

Dictée vocale

La reconnaissance vocale fonctionne entièrement sur votre appareil, grâce au moteur open source Vosk intégré à l'application. Votre voix n'est jamais envoyée sur Internet, ni enregistrée : seul le texte reconnu est placé dans le champ de saisie.

Autorisations demandées

  • Internet : pour joindre votre serveur Ollama et, si vous l'activez, votre serveur Nextcloud.
  • Microphone : uniquement pour la dictée vocale, quand vous la lancez. L'application fonctionne sans cette autorisation.

Supprimer vos données

Vous pouvez supprimer chaque conversation depuis l'application. Désinstaller FolliA, ou effacer ses données dans les paramètres d'Android, supprime tout ce qu'elle a enregistré sur l'appareil. Les copies présentes sur votre serveur Nextcloud ou conservées par votre serveur Ollama restent sous votre contrôle et se suppriment depuis ces serveurs.

Enfants

FolliA ne s'adresse pas aux enfants et ne collecte sciemment aucune donnée les concernant, comme pour tout autre utilisateur.

Ce site web

Ce site n'utilise ni cookies, ni outil de mesure d'audience, ni ressource externe : ses polices sont hébergées avec lui. Il est hébergé par GitHub Pages, qui reçoit donc votre adresse IP lorsque vous le consultez, comme tout hébergeur web.

Modifications
