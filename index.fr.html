FolliA v1.0
🇺🇸 English

L'IA locale et native.
En toute confidentialité.

FolliA est un client natif pour LLMs, conçu pour interagir avec vos propres modèles d'IA sur Android. Rapide, local et sécurisé : vos données restent chez vous.

Télécharger l'APK Code Source ☕ Soutenir sur Ko-fi
🛡️

Souveraineté totale

Connectez vos clés API ou votre propre serveur Ollama via VPN. Zéro intermédiaire, aucun tracking, confidentialité absolue.

🎙️

Mode vocal mains-libres

Discutez naturellement avec votre IA grâce à une logique audio optimisée qui évite les retours et les boucles infinies du micro.

🔄

Persistance en arrière-plan

Ne subissez plus de coupures de génération. Changez d'application librement, l'inférence continue de s'exécuter en sous-marin.

☁️

Synchronisation Nextcloud

Sauvegardez et synchronisez l'intégralité de votre historique de chat de manière privée via une intégration WebDAV native.

📱

Interface adaptative tablette

Profitez d'un affichage double panneau et d'un rail de navigation optimisés pour les grands écrans, loin d'une simple app mobile étirée.

🚀

Mises à jour indépendantes

Restez à jour sans dépendre des stores centralisés grâce à un système autonome qui récupère directement les Releases GitHub.

Fonctionnement de l'architecture

Inférence privée

Faites tourner vos modèles sur votre propre matériel informatique. L'inférence lourde reste à la maison.

Tunnel sécurisé

FolliA communique directement et de manière chiffrée avec votre machine via le réseau local ou votre configuration VPN.

Zéro intermédiaire

Aucun cloud tiers, aucune télémétrie masquée. Vos invites de commande et vos données vous appartiennent exclusivement.
