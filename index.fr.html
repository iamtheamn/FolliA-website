FolliA est un client natif pour LLMs, conçu pour interagir avec vos propres modèles d'IA sur Android. Rapide, local et sécurisé : vos données restent chez vous.

Fonctionnement de l'architecture

Inférence privée

Faites tourner vos modèles sur votre propre matériel informatique. L'inférence lourde reste à la maison.

Connexion directe

FolliA communique directement avec votre machine sur le réseau local. Hors de chez vous, passez par votre VPN ou une adresse HTTPS pour chiffrer les échanges.

Zéro intermédiaire

Aucun cloud tiers, aucune télémétrie masquée. Vos invites de commande et vos données vous appartiennent exclusivement.

Comment démarrer

  1. 1

    Installez Ollama

    Sur votre ordinateur ou votre serveur, installez Ollama, puis téléchargez un modèle, par exemple ollama pull llama3.2.

  2. 2

    Ouvrez-le au réseau local

    Par défaut, Ollama n'accepte que les connexions de la machine elle-même. Définissez la variable OLLAMA_HOST=0.0.0.0, redémarrez Ollama et autorisez le port 11434 dans le pare-feu.

  3. 3

    Connectez FolliA

    Dans Réglages > Serveur, saisissez l'adresse IP de la machine et le port 11434, choisissez votre modèle et commencez à discuter.

Hors de chez vous, passez par votre VPN plutôt que d'exposer le port d'Ollama sur Internet : il n'a pas d'authentification.
