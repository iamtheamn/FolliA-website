FolliA is a native Android client for LLMs, designed to interact with your own AI models. Fast, local, and secure: your data stays where it belongs.

Total Sovereignty

Connect your API keys or your own Ollama server via VPN. Zero intermediates, no tracking, absolute privacy.

Hands-Free Voice Mode

Chat naturally with your AI using optimized audio logic that prevents echo feedback and infinite mic loops.

Background Persistence

No more generation cut-offs. Switch between apps freely while inference continues to process smoothly in the background.

Nextcloud Synchronization

Adaptive Tablet UI

Independent Updates

Private Inference
